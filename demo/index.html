What this demo exercises

Session ownership

One SqlLanguageService opens a document session and accepts atomic updates.

Revision identity

Each accepted edit advances an opaque revision token checked with session.isCurrent().

Dialect context

Built-in dialect handles for PostgreSQL, DuckDB, BigQuery, and Dremio can be switched without reloading the editor.

Walking skeleton

Completion, diagnostics, hover, and navigation are not wired up yet. They will arrive as vertical slices on top of this session API.
